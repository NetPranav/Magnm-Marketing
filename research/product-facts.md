## Cero  (https://github.com/NetPranav/Cero-Terminal) - v2.2.0, MIT, macOS/Linux/Windows
- Desktop terminal (Tauri v2, Rust, React 19, xterm.js). Commands run in a real shell (zsh/bash, PowerShell on Windows).
- Start a line with ">" to make a plain-language request. Cero works out the commands, shows any that change things for approval, runs them, answers from real output.
- `.flow` files: one file, double-click, runs on any OS (picks right install commands). Nothing runs until you click Run.
- Built-in local model (3B default, 2.1 GB; 4B option), runs on your computer. Also Ollama or an API of your choice. API keys live in the system keychain.
- Finds folders/apps by name, asks when two match; Ctrl+C stops a request; /learn and /forget (learns only when told).
- Real footage available in repo: docs/media/cero-demo.mp4 (2.5 min, real app), docs/media/flow-demo.gif, assets/brand/cero-logo-animation.mp4.
- NOT found in README (do not claim): ROS / robotics support.

## LazyLayout  (https://github.com/NetPranav/WebGen) - "Initial Phase", in development
- "AI-native motion design studio": visual editor for interactive motion, effects, components using GSAP, Framer Motion, SVG, CSS.
- Compiles to clean production code you can drop into any codebase.
- Has an AI co-pilot with ghost keyframes + Accept/Discard approval.
- Next.js 16 / React 19. Full-vision features (blueprints, database studio, deployment) are NOT in this build.
- NOT verified (do not claim): "builds animations from wireframes", manual wiring. Confirm with CEO.
