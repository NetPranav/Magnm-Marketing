# Reference library and learnings (motion-graphics films)
Updated 2026-10-17. Files: reference/ (videos + contact sheets). The CEO's standing brief: playbooks/video-directive.md (read it in full before any film).
Rule: borrow techniques, never footage, artwork, type lettering, music or subject matter. All three references are other brands' ads.

## Ref 1 - Edge "net-zero" brand film  (reference/ref1_edge_netzero.mp4)
736x414 16:9, 25fps, 89s, ~49 cuts (avg 1.8s). Narration-led, loud mix (mean -13.8 dB).
Visual identity: flat paper/pastel grounds (cream, pale blue, sage, butter), one hard colour card now and then (teal, orange, near-black). Lots of negative space.
Type: heavy condensed sans for the one key noun (HUGE, CARBON) + small italic serif / handwriting for connecting words ("Something", "Worldwide"). Short phrases appear in step with the voice (1-3 words per card).
Media mix: line-art illustration, cut-out photo collage, boxed real footage, flat geometric shapes, all in one editorial page system.
Furniture: crosshairs, corner brackets, tiny mono captions, arrows - the frame reads as a designed document.
Motion: quick reveal, hold, hard cut. Few transitions. Calm.
Ending: logo-shape sweep + one URL line; a phone mock with a notification as CTA.
Best passages: 0-8s ("Something HUGE" - big/small type contrast over line art); ~40-60s collage of boxed photos with italic captions; final 6s logo sweep.
Feels: intellectual, editorial, human, premium.

## Ref 2 - "MOVE" / Just Jerk x KB Kookmin Card  (reference/ref2_justjerk_kbcard_move.mp4)
736x414 16:9, 23.976fps, 30s. Music-driven (loud, mean -11.7 dB, peaks 0 dB), no narration.
Visual identity: grunge black/white - grain, ink texture, footprint stamps, scratches; one accent: yellow (scribble lines, then a full yellow field near the end). Strictly monochrome otherwise.
Type: one word ("MOVE") restyled every few frames on the beat - stencil, outline, condensed italic, distressed, cut-up - the type swap IS the animation. Korean lines in small bold sans, centred.
Motion: 0-7s slow build (footprints walk in one by one, no cuts) -> 7-12s first hits (black/white flips) -> 16-19.5s burst (cuts every 2-5 frames, type-swap) -> calm yellow field -> end card. Strong fast/slow contrast.
Compositing: dance footage desaturated, halftone texture, shown inside letter-shaped masks or behind giant type; yellow hand-drawn outline traces one dancer (rotoscope accent).
Transitions: footprint stamp wipes, ink smear, black/white inversion on beat, text-mask to footage.
Ending: full yellow field with one sentence -> co-brand lockup small on black. Logo appears once.
Best passages: 0-7s footprint build (stillness before energy); 16-19.5s "MOVE" type burst; 26-28s yellow field.
Feels: energetic, human, street, experimental.

## Ref 3 - YOASOBI "Hajimete no" book promo  (reference/ref3_yoasobi_hajimeteno.mp4)
736x414 16:9, 30fps, 58s. Song-led, quiet mix (mean -21.8 dB), no narration. Only ~12 hard cuts: almost everything moves continuously.
Visual identity: Japanese editorial - manuscript-grid paper, cream ground, then each chapter gets its own flat colour (blue, purple, orange, pink, red) with a subtle repeating pattern. Colour-coding = structure.
Type: vertical and horizontal text mixed; giant cropped characters bleeding off-frame and drifting (camera pan across huge type); delicate small serif captions; text reveals character by character with placeholder blocks that fill in.
Structure: index diagram (a tree of 8 icons = the 4 stories) -> per chapter: colour field -> white "book page" card with title + author -> vertical tagline -> giant author name -> a story line. Same template repeated 4 times with a new colour = rhythm without boredom.
Transitions: paper folds / page turns into the next colour; slow camera drift and push; cards slide in and stack.
Ending: product packshot (book cover), price and release line, then the artist wordmark. Logo once.
Best passages: 0-6s manuscript-grid title; 8-12s page-fold from the index tree into the blue chapter; 12-20s giant cropped name drifting + character-by-character line reveal; 50-58s packshot.
Feels: elegant, intellectual, warm, premium, calm.

## House learnings (from building v2, 2026-10-17)
Keep: stone/ink/lime palette; Anton + Instrument Serif Italic + JetBrains Mono; real labelled footage; claims only from research/product-facts.md; two native layouts (9:16 and 16:9) from one timeline.
Change next time (per the CEO directive):
1. Logo rare: v2 put "MAGNM" on every card (persistent branding) - remove; logo once near the end, optional at the start.
2. Voice optional: v2 narrated every second. Default now = music/sound-design led, on-screen type carries the story; narration only for 1-3 lines if it adds something.
3. Vary motion: v2 used the same mask-rise on every heading and hard cuts everywhere. Use a mix: hard cut, page fold, inversion, type-mask to footage, a type-swap burst, and real stillness.
4. Pace contrast: slow open -> build -> one burst -> calm field -> end. Not a constant 3s-per-card rhythm.
5. Sound design: needs a licensed music bed or our own synthesized pulses + CC0 hits; avoid unlicensed music. Mix around -14 LUFS for social.
6. Texture: references use paper grain / ink; add a subtle grain overlay (generated, not copied) so flat fields don't look digital-empty.
7. Typography must stay readable: hold key lines >= 1.2s; no paragraphs.
8. Always QA the actual export: frames across the whole film, audio levels, both aspect ratios.

## Learnings from film 20261024 ("See it before it runs", 2026-10-17)
- Topic first: Researcher evidence -> Strategist thesis -> Writer shot script -> Reviewer, BEFORE design. One tension + proof beats a feature tour.
- No voice worked: real UI text ("Nothing runs until you approve", "Declined in the confirmation dialog", "Stopped.") carries the claims; type only frames them.
- Reviewer caught: slogan-adjacent copy, over-claims ("It doesn't guess", "hand on Enter"), unreadable lime fill behind light text (use underlines), off-by-frame sync, type covered by footage boxes.
- Technique: footage-through-letters = ink layer + white type with mix-blend-mode:darken over the video, plus a 2px stone outline layer; zoom through a letter STROKE, not a counter. Original synth score + CC0 keys/clicks synced to real UI events.
- Delivery: device commit limit 30 MB/file -> 2-pass ~4.3 Mbps encode for the folder.
