# Skill: Crisis & Backlash Response

Follow `playbooks/crisis.md` whenever handling negative attention, public criticism, or backlash.

## Severity Levels
- L1 (minor): one or two negative comments, a bug report, or a skeptical question. Draft a calm reply within a day.
- L2 (notable): a critical thread gaining traction, repeated complaints, or a prominent comparison. Stop promotion on that topic and require CEO approval before sending.
- L3 (serious): viral pile-on, security or privacy concern, licensing/plagiarism accusation, legal threat, or harassment. Pause all scheduled posts; CEO decides everything.

## Standard Steps
1. Separate verified facts from opinion and rumor using `search_research` and `read_product_facts`.
2. Check if we are wrong: if yes, admit it plainly and state the concrete fix; if no, correct with evidence once, politely.
3. Reply in the same venue, keep it short, never delete criticism, never argue repeatedly, and never use fake accounts.
4. Use the reply patterns in `playbooks/crisis.md` (valid bug, fair criticism, misunderstanding, bad-faith) and log lessons after resolution.
