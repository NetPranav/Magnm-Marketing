## Replying to comments (first 24 hours)
Reply to everything within a few hours; it helps reach. Safe answers:
- "Does it run on Windows/Linux?"
  "There are builds for macOS, Linux and Windows. We've tested the most on macOS so far, so tell us if anything breaks."
- "Copilot CLI / X already asks for approval."
  "Fair. Our focus is showing the exact command, and questions don't need a dialog at all."
- "Is it fully local?"
  "The built-in model and Ollama keep requests on your computer. If you choose a cloud API, those requests go to that provider."
- "Can I see the code?"
  "Yes, it's MIT." Then add the GitHub link github.com/NetPranav/Cero-Terminal. Only use this link once you've confirmed it's the right public repo.

Never claim: accuracy numbers, "100% offline", "never runs anything without asking", or anything about LazyLayout.
