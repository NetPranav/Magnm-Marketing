## 1. Topic and thesis

**Topic: "See it before it runs."** (Researcher's #1, R§4, with #2 "It asks. It doesn't guess." folded in as a supporting beat.)

**Thesis (one sentence):** Cero puts AI in your terminal without taking your hand off the controls - questions are answered from real output, and anything that changes your files, system or network stops and shows you the exact command before it runs.

Why it beats the alternatives:
- **It answers the live fear.** The #1 worry about AI in the terminal right now is an agent running a destructive command on its own (W1 rm -rf home folder, W2 Gemini CLI file deletion, W3 Replit DB deletion) and a trust gap (W4: 46% distrust AI accuracy). A film that opens on that tension earns attention from developers instead of asking for it.
- **The proof is real, unedited UI.** The approval dialog literally says "Cero will run exactly what is shown below. Nothing runs until you approve." (demo 52-55s). With no voice-over the on-screen app text IS the script (directive sec 6) - we do not have to invent wording or claims.
- **One feeling, one motif.** Control, carried by one repeated visual object: the dialog with the exact command. That gives the designers a motif to restyle (burst, mask, fold) without a feature list (directive Phase C: "avoid a list of features").
- **It handles approval fatigue too.** W1 notes devs skip permissions "because the alternative is approving every ls and cat". Cero's split (read-only runs, changes ask - F2, F2a) answers both camps, which a plain "it asks permission" film would not.
- Alternatives rejected as the lead:
  - #3 ".flow - one file, any OS": the "any OS" half is only verified on macOS (F13, R§5 #7). Kept only as one approval shot (demo 82-87s), never as a cross-OS story.
  - #4 "Your terminal, your model": static proof only (settings.png, "AI: local" status bar). Good as a closing fact, too thin for a film.
  - #5 "/learn": nice colour, no sourced tension. Leave out.
  - Feature tour (previous plan): failed - it pulled in LazyLayout and turned into slides. Not repeated.

## 2. Audience, placement, feel / understand / do

**Who (primary):** developers who live in the terminal and are curious about, or burned by, AI agents in the shell - India first, global second (config.md). Secondary: technical leads who have to say yes/no to AI tools touching dev machines (privacy/IP angle, W9).
Not the audience for this film: robotics/ROS users (ROS is a do-not-claim, R§5 #1).

**Where they will see it:**
| Platform | Format | Viewing context | Implication |
|---|---|---|---|
| IG Reels | 9:16 | sound often on, thumb-scroll, phone | Hook must land in the first 2s; every terminal shot 2-3x crop (R§2a legibility) |
| LinkedIn | 16:9 (or 9:16 native video) | sound OFF by default, desk/phone | Story must read with zero audio - type carries everything |
| X | 16:9 | autoplay muted, dev audience, skeptical replies | First frame must already be a readable line |
| YouTube | 16:9 (+ 9:16 as a Short) | channel not created yet (config.md) | Publish once channel exists; same cut |

**Feel:** calm control. Relief, not fear. The opening tension is a held breath; the rest of the film exhales. Not "AI is dangerous", but "here is how it should behave".

**Understand (3 things max):**
1. Cero is a terminal you can ask in plain words (start a line with ">").
2. Anything that changes your files, system or network shows you the exact command and waits.
3. You can say no, or stop it - and it really stops.

**Do:** visit **magnm-org.vercel.app** (default CTA, per brief). Secondary, only if the CEO confirms the URL: the Cero GitHub repo (see Q1). One CTA on screen, not two.

## 6. Risks: skeptical-developer pushback and how the film pre-empts it
| Likely comment | Pre-empt in film | Prepared reply (for Community, CMO to approve) |
|---|---|---|
| "Copilot CLI / others already ask for approval." | We never say "only" or "first". The film is about the exact command + questions not needing permission + asks-instead-of-guessing - the combination. | "Yes, approval is becoming standard - good. Cero's take: read-only questions just answer, anything that changes things shows the exact command, and the AI can run on your own machine." |
| "Approving every command is unusable." | M2 beat shows a question answered with no dialog. | "Read-only requests run without a dialog; only changes ask first." |
| "The prompt didn't flag the dangerous part last time (rm -rf ~/)." | The dialog shows the literal command string, not a summary. | "It shows the exact command it will run, verbatim." Do not claim it detects/blocks destructive patterns. |
| "A 3B model in a terminal? It'll be wrong." | We make no intelligence claim; we show real answers from real output, and that it asks when unsure. | "It answers from real command output, asks when a name is ambiguous, and you can use Ollama or your own API instead." |
| "Is it actually local?" | Only "The built-in model runs on your computer." | "With the built-in model or Ollama, requests stay on your computer. If you add a cloud key, that provider sees the request." |
| "Fear-mongering / dunking on other tools." | No names, no incident footage; tension is two calm lines. | n/a |
| "Does it work on Windows/Linux?" | No OS claim in the film. | Honest: installers exist for all three; hand-tested on macOS so far; Linux/Windows feedback welcome. (CEO to approve wording, Q3.) |
| "Installer is unsigned / macOS warns me." | Not in film. | Honest acknowledgement + how to open (CEO to approve; F14). |
| "This is just staged marketing UI." | Footage is the real app, unedited, labelled "real app footage" in a small mono caption. | Link to repo demo. |
| "The Cancel shot shows it failed to open the folder." | Shot is framed as "you said no, it stopped" - the point is that Cancel works. | n/a |

Brand risk: first-ever post on 0-follower accounts. A film that overclaims gets corrected in replies with no audience to defend it. Every line above traces to product-facts or real UI text - Reviewer should check that table, not taste.

Assumptions (not data-backed): (a) the safety/control angle resonates more than a capability angle with this audience - based on W1-W4, not on our own engagement data (we have none yet); (b) silent-viewing on LinkedIn/X - industry common knowledge, not measured by us; (c) 46s holds attention on Reels - may need the 35s cut (sec 4).

Measure after posting (for Analytics): 3s hold rate, average watch %, website clicks from link-in-bio / post link, and whether comments are about control/safety (thesis landed) or "what is this?" (hook/reveal unclear).
