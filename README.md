# Magnm Marketing Team (basic v1)

A CMO agent that checks our social profiles on a schedule, plans the next posts, and hands work to specialist agents through files in this folder. Every handoff and every output is a file, so you can open anything any agent made.

## Start here
- RUNBOOK.md        how to run the team (scheduled or manually)
- config.md         accounts, products, audience, cadence, voice (edit this to tailor the team)
- agents/           one prompt file per role
- templates/        formats for briefs, outputs, reviews, logs
- state/board.md    live pipeline: what is planned, in progress, awaiting you
- state/activity.log every handoff, one line each (who -> who, brief id, file)
- logs/             CMO check-ins (one file per run)
- plan/plan.md      posting slots for the coming 2 weeks
- briefs/           CMO -> agent task briefs
- outputs/          what agents produced (strategy, growth, community, analytics, research, feedback, scripts, posts, visuals)
- playbooks/        crisis and launch playbooks
- state/strategy.md current positioning and roadmap
- reviews/          Reviewer verdicts and Advisor advice

## Team
CMO (scheduled, the only agent that runs on its own) -> Strategist (plans), Growth Lead (how to market), Advisor (what to post), Listener (reads feedback), Community and Crisis Manager (replies, backlash), Analyst (numbers), Video Producer (makes videos with video-skills/magnm-video), Researcher, Writer, Designer, Reviewer. All run only when the CMO briefs them.

Playbooks: playbooks/crisis.md (backlash), playbooks/launch.md (launch checklist).

## Hard rules for every agent
1. Publishing (CEO, 2026-10-18): only the CMO publishes, and only Reviewer-approved text/text+image posts after the CEO's daily "yes" (playbooks/operating-model.md section 4). All other agents and agy are read-only on social platforms: never post, comment, reply, DM, follow, like or submit.
2. Never create accounts or enter passwords.
3. Never invent metrics, testimonials, quotes, or product features. Cite where each fact came from.
4. Everything you do is written to a file in this folder.
5. The products are spelled Cero and LazyLayout.
- video-skills/    video generator (magnm-video, forked from brag) and vendored engines/skills
